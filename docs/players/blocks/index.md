# Blocks
Chisels & Bits provides several blocks which you can use to create your magical buildings, structures or designs.
Some blocks provide core functionality, while others help you manipulate patterns, or allow you to easily duplicate a pattern, or chiseled block.

Use the menu (generally on the left) to get more information on a block of your choosing.
