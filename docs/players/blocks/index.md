# Blocks

Chisels & Bits provides several blocks you can use to create intricate buildings, structures and designs.
Some are purely functional, while others help you manipulate, store or duplicate patterns and chiseled blocks.

## Available Blocks

### [Chiseled Block](chiseled-block.md)
The heart of the mod. A block that stores up to 16 × 16 × 16 individual bits sculpted from any supported material. Supports rotations, mirroring, water-logging and many vanilla block properties.

### [Modification Table](modification-table.md)
A crafting-station-like block used to mirror, rotate and otherwise transform chiseled blocks or patterns before placing them in the world.

### [Bit Storage](bit-storage.md)
A block-sized container for storing large quantities of a single bit type. Fill it with bits to keep your inventory tidy.

### [Chisel Station](chiseled-printer.md)
A block that lets you apply a stored pattern to a target block in the world, duplicating complex designs quickly without having to chisel them by hand.
