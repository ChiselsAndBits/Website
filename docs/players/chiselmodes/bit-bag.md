# Bit Bag

The Bit Bag is a special storage item for holding large quantities of bits (the tiny pieces you chisel from blocks).

## How to Craft
- **Bit Bag:** String + Wool + Leather

## How to Use
- Right-click while holding the Bit Bag to open its inventory.
- Automatically collects bits you pick up.
- Can store thousands of bits of different types.

## Tips
- Dye the Bit Bag with any color by combining it with dye in a crafting grid.
- Useful for large building projects.
