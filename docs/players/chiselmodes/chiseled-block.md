# Chiseled Blocks

Chiseled Blocks are blocks that have been sculpted using a chisel. You can create detailed designs by removing or adding bits.

## How to Create
- Use a chisel on any standard block to start chiseling.
- Remove or add bits to shape the block as you like.

## How to Use
- Chiseled blocks can be placed like any other block.
- They retain their custom shape and appearance.

## Tips
- Use the Bit Bag to collect and reuse bits.
- Chiseled blocks can be copied using patterns and the Chiseled Printer.
