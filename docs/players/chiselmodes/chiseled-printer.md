# Chiseled Printer

The Chiseled Printer is a special block that allows you to duplicate chiseled designs using patterns and bits.

## How to Craft
- **Chiseled Printer:** Stone + Iron Ingot + Glass Pane

## How to Use
1. Place a pattern with a saved design into the printer.
2. Insert the required bits.
3. Activate the printer to create a copy of the design.

## Tips
- Useful for mass-producing detailed blocks.
- Requires the correct type and amount of bits for the design.
