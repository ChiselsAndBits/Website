# Extrude 4

![Extrude icon](/icons/chiselmodes/connected_material.png)

Selects connected same-material bits and extrudes/intrudes by 4 bits along the hit face.

## Details

| Property | Value                  |
|----------|------------------------|
| Mode id  | `connected_material_4` |
| Group    | Extrude (Connected Material) |
| Depth    | 4 bits                 |

## Usage

- **Left-click (chisel):** Removes connected same-material bits reachable within 4 bits of the face.
- **Right-click (place):** Fills connected air bits reachable within 4 bits of the face with the held material.

## Tips

> [!TIP]
> Quarter-block extrusion depth — handy for reshaping thicker protrusions of a connected material.
