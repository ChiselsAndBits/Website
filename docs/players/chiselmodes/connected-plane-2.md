# Connected Plane 2

![Connected Plane icon](/icons/chiselmodes/connected_plane.png)

Connected Plane flood-fill extended to 2 bits of depth from the hit surface.

## Details

| Property | Value               |
|----------|---------------------|
| Mode id  | `connected_plane_2` |
| Group    | Connected Plane     |
| Depth    | 2 bits              |

## Usage

- **Left-click (chisel):** Removes all connected same-state bits on the face up to 2 bits deep.
- **Right-click (place):** Fills connected air bits on the face up to 2 bits deep with the held material.

## Tips

> [!TIP]
> Slightly thicker reach than Connected Plane 1, useful for removing thin surface coatings of a single material.
