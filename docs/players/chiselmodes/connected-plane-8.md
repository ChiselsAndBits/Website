# Connected Plane 8

![Connected Plane icon](/icons/chiselmodes/connected_plane.png)

Connected Plane flood-fill at maximum depth — 8 bits from the hit surface (half the block).

## Details

| Property | Value               |
|----------|---------------------|
| Mode id  | `connected_plane_8` |
| Group    | Connected Plane     |
| Depth    | 8 bits              |

## Usage

- **Left-click (chisel):** Removes all connected same-state bits on the face up to 8 bits deep.
- **Right-click (place):** Fills connected air bits on the face up to 8 bits deep with the held material.

## Tips

> [!TIP]
> The deepest connected plane option — great for hollowing confined regions of a complex design without touching adjacent material pockets.
