# Drawn Cube

![Drawn Cube icon](/icons/chiselmodes/drawn_cube.png)

Click and drag to define a custom cuboid selection. The first click sets the anchor corner; releasing the button applies the operation to the entire drawn box.

## Details

| Property  | Value        |
|-----------|--------------|
| Mode id   | `drawn_cube` |
| Group     | Draw         |
| Selection | Drag-defined cuboid |

## Usage

- **Hold Left-click + drag (chisel):** Draws the selection box while held; releases to remove all bits inside the box.
- **Hold Right-click + drag (place):** Draws the selection box; releases to fill all air bits inside the box with the held material.

> [!NOTE]
> This is a multi-click mode — you must **hold** the mouse button while dragging to define the region, then release to apply.

## Tips

> [!TIP]
> Perfect for carving out rectangular rooms, tunnels, or any box-shaped volume in one fluid motion.
