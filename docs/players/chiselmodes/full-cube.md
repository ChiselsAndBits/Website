# Full Cube

![Full Cube icon](/icons/chiselmodes/same_material.png)

Selects the full 16 × 16 × 16 bit volume — the entire block — aligned to block boundaries.

## Details

| Property  | Value        |
|-----------|--------------|
| Mode id   | `full_cube`  |
| Group     | Cubed Aligned |
| Selection | 16 × 16 × 16 bits (full block) |

## Usage

- **Left-click (chisel):** Removes every bit inside the targeted block, effectively clearing it entirely.
- **Right-click (place):** Fills every air bit inside the targeted block with the held material.

## Tips

> [!TIP]
> Equivalent to breaking and placing a full block via the bit system — useful for resetting a chiseled block or filling one completely.
