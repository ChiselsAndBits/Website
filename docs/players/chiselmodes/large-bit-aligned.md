# Large Bit Aligned

![Large Bit Aligned icon](/icons/chiselmodes/snap8.png)

An 8 × 8 × 8 cube that snaps to a fixed 1/2-block grid.

## Details

| Property  | Value               |
|-----------|---------------------|
| Mode id   | `large_bit_aligned` |
| Group     | Cubed Aligned       |
| Selection | 8 × 8 × 8 bits, grid snapped to 1/2 |

## Usage

- **Left-click (chisel):** Removes the aligned half-block cube at the snapped grid cell.
- **Right-click (place):** Fills the snapped half-block cell with the held material.

## Tips

> [!TIP]
> Half-block alignment — great for stair-like structures, ledges, and symmetric halved blocks.
