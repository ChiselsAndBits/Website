# Large Sphere

![Large Sphere icon](/icons/chiselmodes/sphere_large.png)

Creates or removes the largest spherical volume — a full 16-bit (full block width) diameter sphere, potentially spanning multiple adjacent chiseled blocks.

## Details

| Property  | Value          |
|-----------|----------------|
| Mode id   | `large_sphere` |
| Group     | Sphere         |
| Diameter  | 16 bits        |

## Usage

- **Left-click (chisel):** Removes all bits within the 16-bit-diameter sphere centered on the targeted bit.
- **Right-click (place):** Fills all air bits within the sphere with the held material.

## Tips

> [!TIP]
> The sphere can extend across block boundaries, allowing you to carve round arches, dome caps, or full circular holes spanning a whole block.
