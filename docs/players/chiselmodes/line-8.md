# Line 8 x 8

![Line 8 icon](/icons/chiselmodes/line8.png)

Extends the widest line — an 8 × 8 thick column — from the targeted bit along the hit direction.

## Details

| Property  | Value     |
|-----------|-----------|
| Mode id   | `line_8`  |
| Group     | Line      |
| Thickness | 8 × 8 bits |

## Usage

- **Left-click (chisel):** Removes all bits in the 8 × 8 column in the opposite of the hit direction.
- **Right-click (place):** Fills all air bits in the 8 × 8 column in the hit direction.

## Tips

> [!TIP]
> Perfect for cutting half-block-wide shafts or creating thick structural columns in a single click.
