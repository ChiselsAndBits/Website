# Medium Sphere

![Medium Sphere icon](/icons/chiselmodes/sphere_medium.png)

Creates or removes a medium spherical volume. Diameter is 8 bits — half a block wide.

## Details

| Property  | Value           |
|-----------|-----------------|
| Mode id   | `medium_sphere` |
| Group     | Sphere          |
| Diameter  | 8 bits          |

## Usage

- **Left-click (chisel):** Removes all bits within the 8-bit-diameter sphere centered on the targeted bit.
- **Right-click (place):** Fills all air bits within the sphere with the held material.

## Tips

> [!TIP]
> Useful for round windows, porthole shapes, or spherical cavities that need to be a noticeable size.
