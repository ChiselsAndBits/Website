# Plane 2

![Plane 2 icon](/icons/chiselmodes/plane2.png)

Edits a full 16 × 16 bit face slab that is 2 bits deep from the hit surface.

## Details

| Property | Value     |
|----------|-----------|
| Mode id  | `plane_2` |
| Group    | Plane     |
| Depth    | 2 bits    |

## Usage

- **Left-click (chisel):** Removes all bits on the face up to 2 bits deep.
- **Right-click (place):** Fills all air bits within 2 bits of the face with the held material.

## Tips

> [!TIP]
> Thicker than Plane 1 — useful for adding raised decorations or recessed panels.
