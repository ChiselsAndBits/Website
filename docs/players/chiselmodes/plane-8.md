# Plane 8

![Plane 8 icon](/icons/chiselmodes/plane8.png)

Edits the deepest plane — a full 16 × 16 bit face slab that is 8 bits (half the block) deep from the hit surface.

## Details

| Property | Value     |
|----------|-----------|
| Mode id  | `plane_8` |
| Group    | Plane     |
| Depth    | 8 bits    |

## Usage

- **Left-click (chisel):** Removes all bits on the face up to 8 bits deep (half the block).
- **Right-click (place):** Fills all air bits within 8 bits of the face with the held material.

## Tips

> [!TIP]
> Effectively halves the block from one side in a single action.
