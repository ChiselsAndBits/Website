# Single Bit

![Single Bit icon](/icons/chiselmodes/bit.png)

The most precise chisel mode. Targets exactly one bit (1/16th of a block side) at a time.

## Details

| Property  | Value        |
|-----------|--------------|
| Mode id   | `single_bit` |
| Group     | Cubed        |
| Selection | 1 × 1 × 1 bit |

## Usage

- **Left-click (chisel):** Removes the single targeted bit and returns it to your inventory.
- **Right-click (place):** Places one bit of the material you are holding into the targeted air slot.

## Tips

> [!TIP]
> Use this mode for fine detail work where every bit matters. It is perfect for adding or removing small decorative elements.
