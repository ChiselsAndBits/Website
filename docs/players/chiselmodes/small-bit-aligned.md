# Small Bit Aligned

![Small Bit Aligned icon](/icons/chiselmodes/snap2.png)

A 2 × 2 × 2 cube that snaps to a fixed 1/8-block grid rather than free-placing at the cursor position.

## Details

| Property  | Value               |
|-----------|---------------------|
| Mode id   | `small_bit_aligned` |
| Group     | Cubed Aligned       |
| Selection | 2 × 2 × 2 bits, grid snapped to 1/8 |

## Usage

- **Left-click (chisel):** Removes the aligned 2 × 2 × 2 cube at the snapped grid cell containing the targeted bit.
- **Right-click (place):** Fills the snapped grid cell with the held material.

## Tips

> [!TIP]
> Use aligned modes when you need perfectly repeating patterns at regular intervals — the grid prevents misalignment between adjacent edits.
