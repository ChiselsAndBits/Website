# Small Bit

![Small Bit icon](/icons/chiselmodes/cube_small.png)

Targets a 2 × 2 × 2 cube of bits centered around the targeted position.

## Details

| Property  | Value        |
|-----------|--------------|
| Mode id   | `small_bit`  |
| Group     | Cubed        |
| Selection | 2 × 2 × 2 bits |

## Usage

- **Left-click (chisel):** Removes all bits in the 2 × 2 × 2 cube and returns them to your inventory.
- **Right-click (place):** Fills all air bits in the 2 × 2 × 2 area with the held material.

## Tips

> [!TIP]
> Faster than Single Bit for rough shaping while still keeping reasonable precision.
