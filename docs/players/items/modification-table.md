# Modification Table

The Modification Table is used to apply special modifications to chiseled blocks and items.

## How to Craft
- **Modification Table:** Planks + Iron Ingot + Stone Slab

## How to Use
- Place a chiseled block or item in the table.
- Select a modification to apply (e.g., sealing, pattern transfer).
- Retrieve the modified item.

## Tips
- Some modifications require additional materials (like Sealant or Quill).
- Experiment with different modifications for advanced builds.
